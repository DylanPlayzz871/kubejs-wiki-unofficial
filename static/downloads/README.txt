DROP YOUR WINDOWS APP HERE

1. Copy your app's .exe file into this folder (static/downloads).
2. Keep just one .exe here. You can keep its original filename.
3. Rebuild and deploy the website using your normal publishing process.
   If the local development server is running, restart it after adding,
   replacing, or renaming the file.

The Downloads page automatically finds the .exe when the site starts or builds.
Without an .exe, it shows "Coming soon". If more than one .exe is present,
the first filename in alphabetical order is selected.

To update the app, replace the old .exe here, then rebuild and deploy again.
Files in this folder become publicly downloadable when the site is published.

APP ICON

Save your app icon as easy-command-workshop.png in this same folder.
Use a square PNG (256 x 256 pixels or larger recommended), ideally with a
transparent background. The page will show it next to Easy command workshop.
Until you add it, a command-window placeholder is shown instead.
The browser cannot display the icon embedded inside the .exe directly.
